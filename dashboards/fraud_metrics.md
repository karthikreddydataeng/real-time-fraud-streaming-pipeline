# Fraud Monitoring Metrics

This document lists example metrics that fraud and analytics teams may monitor from the streaming pipeline.

## Key Metrics

- Total transactions processed
- High risk transactions
- Failed transactions
- Average transaction amount
- Transactions by merchant category
- Transactions by country
- High risk transaction percentage
- Fraud alerts by hour

## Example Dashboard Sections

### Transaction Volume

Tracks the number of transactions processed by hour or day.

### Fraud Risk Summary

Shows the number and percentage of transactions flagged by fraud rules.

### Location Review

Highlights transactions from unusual or non-primary locations.

### Merchant Category Review

Shows transaction activity by merchant category.

### Failed Transaction Monitoring

Tracks failed transaction attempts that may require investigation.
